# Restaurant Revenue Prediction using Multiple Regression

Machine-learning project that predicts restaurant revenue using multiple linear regression with three features: number of items, orders placed, and restaurant ID. Includes a recruiter-friendly Streamlit demo and a FastAPI endpoint for Render deployment.

**Note:** The uploaded notebook already contained the `joblib.dump(model, "model.pkl")` save step, so its original code was preserved without unnecessary modification. The deployment `model.pkl` and sample CSV are provided for standalone testing because the notebook's `revenue_prediction.csv` was not included in the uploaded file.
